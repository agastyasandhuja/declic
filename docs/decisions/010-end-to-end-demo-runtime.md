# End-to-end demo runtime

Accepted by the user's November 14 integration request.

The user authorizes consolidation of all feature branches and integration changes
across the mobile, academic, and learning boundaries. Preserve the déclic UI and
existing owner interfaces wherever possible. Atlas remains the application
store; Supabase remains Auth and private media Storage. No additional service.

For this demo each student enters a Canvas personal access token generated by
that student. Institutional OAuth is unavailable. The backend verifies the token
against the configured institution and stores authenticated encryption bound to
the verified app user and provider. Tokens never enter model prompts, logs,
renderers, Git, or mobile persistence. A disconnect revokes backend use.

Long-running work uses persistent leased jobs with bounded parallelism. Reuse
compatible topic preparation and media within the user's private scope. Shared
public reuse still requires reviewed generic lineage. Gemini output and Canvas
material remain untrusted and schema-validated.

The user's requested unattended background generation requires an explicit
private-demo automatic publication policy, separate from manually reviewed
public publication. Automated checks must be recorded as automated checks,
never represented as human approval. Failed checks keep assets out of feeds.

The deterministic progressive-density, course-fairness and retrieval policy is
the initial fallback. Any learned policy is experimental until evaluated with
real delayed retrieval data; test mechanics do not establish learning gains.

The integrated all-course request adds a practice fallback to the prior
assessment-only Canvas planner: when upcoming work lacks teachable source content,
use source-backed current-unit material as suggested practice, with unknown exam
scope and no invented date or assessment linkage. It ranks below verified upcoming
assessment work. Past-assessment-only material remains ineligible. All validated
requests queue fairly across courses; a per-course initial batch must not silently
discard the remaining work.

Live student verification exposed administrative assignment titles and deadlines
being promoted to lessons, plus selected PDF text being lost because its optional
parser was absent. PDF extraction is now a pinned runtime dependency. Unchanged
reimports retain owner-scoped extracted text; file update metadata and extraction
policy changes invalidate the cache. Deadline metadata informs priority but does
not substantiate a teaching fact. Plans must reference matching lecture/page/file
content. Administrative or insufficient-source model output produces an explicit
unavailable result without publishing a quiz or starting paid video generation.
Grounded lecture practice can coexist with upcoming assignments, without implying
confirmed exam coverage. The live test authorizes five selected video jobs; the
worker allowlist persists independently of process restarts.

Retrieval reserves bounded reads for lecture/chapter sources. If a course map has
no grounded objectives but real teaching excerpts exist, one bounded Gemini call
may recover up to three practice concepts with two distinct exact source quotes
each. Those units remain private, source-bound and unknown in exam scope. PDF
glyph corruption is not silently corrected, and learning outcomes are not lesson
facts. Identical approved fact sets within the existing owner/compatibility scope
reuse one canonical topic even if their generated headings differ.

Generic course visuals opt into `Brief.visual_strategy=semantic_diagram`. This
adds bounded authored comparison, sequence and cause/effect diagrams with at most
four short node labels and validated edges. Model output remains data, never
executable rendering code. Existing photographic/specialized template policies
are unchanged. Every asserted label and relation is reviewed against the approved
facts; frame/media checks still apply. Automatic repair stays under the original
queued recipe, with repair evidence kept in local artifacts. The v9 renderer uses
two bounded frame workers; this is not a measured ten-minute completion promise.
