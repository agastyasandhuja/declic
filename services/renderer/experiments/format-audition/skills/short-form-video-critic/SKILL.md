# Short Form Video Critic

Read the actual exported MP4, frame contact sheet, script and manifest limitation. Check opening, causal transformations, mobile text, caption bounds, motion continuity and ending. Report sample ID, timestamp, severity, observable defect and component-level repair. Separate defects from taste. Use review.py for cached Opus still criticism if available, but do not call that an audio or motion review. A render exit code is not a visual pass. Keep human Keep/Potential/Pass feedback pending until received.

These instructions are local candidate skills for the format audition. User review determines which formats to retain; they are not globally installed.

Latest sample-22 guidance: follow the renderer ANIMATION_STANDARD.md. Require
task-facing actors, coherent eyelines, attached held props, supported/navigable
paths, anticipation/action/follow-through, and reviewed camera/occlusion staging
for every shot. Use shared white single-word captions. Codex authors reusable
assets and fixes directly; a paid Claude review is optional, not mandatory.
