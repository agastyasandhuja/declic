# Format Router

For physical concepts with direct everyday consequences, prioritize the
`real-world-humor` story family endorsed through sample 21: varied situations,
cause-linked jokes, then a visual mechanism. Read ../real-world-humor/SKILL.md.
Keep other formats available for abstract topics where a literal real-world
story would conceal or distort the concept.

Read ../../../CREATIVE_DIRECTION.md first. New auditions default to college-level course concepts, not multiplication or elementary arithmetic. A relatable story may introduce a rigorous idea; keep the actual objective at college level. Do not regenerate the old 19 samples merely to meet this new direction.

Read the candidate manifests in ../../manifests. Route to a mechanism that visibly demonstrates the supplied objective: a timeline needs time-dependent states; comparison needs the same units; character rescue needs a real causal obstacle. The catalog is an audition, not an approved general-topic renderer. Respect the status and parameterization_limit. Return the selected ID, one-sentence reason, central question, and any missing evidence or asset. Do not route a real map or 3D request to an illustrative proxy without labeling the distinction.

These instructions are local candidate skills for the format audition. User review determines which formats to retain; they are not globally installed.
