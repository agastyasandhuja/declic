# Storyboard Director

Read ../../../CREATIVE_DIRECTION.md for the latest correction: use straightforward everyday consequences followed by a visual explanation. On-screen text is restricted to speech captions and essential diagram numbers/letters. No branding, headings, badges, character names or slogans. The first friction cartoon was rejected as not good enough; use ../../../friction-story-v2 as the revised candidate, not proof of an approved style.

Inspect the end state of each physical action as well as its midpoint. A fall must reach a supported landing pose; dropped objects must contact the floor; collisions must visibly transfer momentum or stop motion through contact. Do not leave a character suspended in an anticipation pose for the rest of a scene. Keep hands, held objects and leashes attached throughout articulated motion. Validate action timing against the spoken line and review actual encoded frames before calling an action complete.

For suitable topics, dramatize a concrete counterfactual or example story before explaining the mechanism. Use a character's goal, a visible failure, a reaction, a causal close-up and a payoff. Characters may be original, fictional or clearly portrayed public-figure parodies according to the user's brief; do not claim a synthetic performance is authentic. Consult current evidence and Opus for topical character selection without inventing TikTok trend rankings. The friction-story audition is a layered cartoon with physical actions, distinct actors and a college mechanics payoff, not a replacement for every format. Keep comedy causally consistent: an unforced object cannot spontaneously speed up, and a collision can stop it even when tangential friction is zero.

Read ../../catalog.py and the selected manifest as worked examples. Specify each scene’s narration, object state before and after, learning purpose, factual support, and timing. Preserve object identity across causal steps. Replacing an equation, changing a palette, or zooming is not a new explanatory mechanism. Keep text inside the 1080×1920 canvas safe area and reserve the caption band. Treat 20–45 seconds as an audition range; production spoken-video contracts still require 30–60 seconds. Do not silently change public format IDs.

These instructions are local candidate skills for the format audition. User review determines which formats to retain; they are not globally installed.
